# Farm Logout Reminder

Eine Client-only Fabric-Mod für Minecraft **26.3**. Beim Ausloggen vom Server
`smp.germanpvp.de` erscheint die Frage:

> Hast du die Farm ausgeschaltet?

## Bauen

Voraussetzungen:

- Java 25
- Gradle 9.8.2 oder der Fabric-Gradle-Wrapper

Im Projektordner ausführen:

```bash
gradle build
```

Die fertige Mod liegt danach unter `build/libs/`.
